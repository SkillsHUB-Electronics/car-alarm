Measurement points

Place a flat obstacle at a known distance (measure with a ruler or tape from the sensor face), enter the true distance and press Measure. The device averages 10 raw readings. Take at least 4 spread-out points (e.g. 20, 50, 100, 200 cm).

INA219 calibration (voltage & current)

Measure the same point with a multimeter, enter the real values and press Calibrate. The device keeps per-mille gains and a current offset in EEPROM (separate block). Needs a firmware built with POWER_ENABLED=1 and INA enabled in Settings. For the zero offset, disconnect the load first.

Not connected

Mount the unit in the car (MPU +Y facing forward), pick a class, press Record, perform the manoeuvre, then Stop. The device sends 8 features per second over USB. Data can also be imported from a CSV exported by the Android app. Recording while driving is unsafe: have someone else operate it, or use the app on the phone.

How to create the token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → this repository only.
  3. Permissions → Repository → Actions: Read and write. Nothing else.
  4. Short expiry (e.g. 30 days). Paste the token above.

The token is sent only to api.github.com. It is never stored on the server. If you tick Remember it is saved in this browser’s local storage, readable by any script on this page: leave it unticked on a shared computer and revoke the token when you are done.

Troubleshooting

Can’t connectClose other apps using the port (Arduino IDE Serial Monitor), replug the cable, and use Chrome or Edge.
Distance shows —No echo received. Check the sensor wiring and aim.
Z is not about 1 gReset the UNO while the unit is level and still.
LCD is blankRun Scan I²C and set the address, usually 0x27 or 0x3F.
